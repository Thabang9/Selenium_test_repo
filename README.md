# Selenium Web Automation Test

This project automates the testing of `https://practicesoftwaretesting.com/` using Selenium WebDriver in Java.

## Prerequisites

- Java Development Kit (JDK) installed
- ChromeDriver installed and path updated
- Selenium WebDriver dependency added

## Installation

1. Clone the repository:
   ```sh
   git clone https://github.com/selenium_test_repo.git

	2.	Open the project in an IDE like IntelliJ or Eclipse.
	3.	Update the chromedriver path in MainTest.java.
	4.	Run the test.
